# Design Patterns com Java: Dos Clássicos (GoF) ao Spring Framework

Projeto prático desenvolvido para o desafio da **DIO (Digital Innovation One)**, focado no estudo, na implementação e na aplicação dos principais **Padrões de Projeto (Design Patterns)** do GoF (*Gang of Four*).

O repositório aborda as soluções em duas etapas: **Java Puro** (para compreensão da estrutura e dos conceitos) e **Spring Framework** (para aplicação em APIs REST com injeção de dependência).

---

## 🎯 Objetivo do Projeto

Demonstrar a aplicação prática de padrões arquiteturais em Java para garantir código limpo, desacoplado, reutilizável e de fácil manutenção no dia a dia do desenvolvimento de software.

---

## 📚 Conteúdo e Módulos

| Módulo | Tema / Foco Principal |
| :--- | :--- |
| **Fundamentos** | Introdução teórica aos Padrões de Projeto GoF |
| **Java Puro** | Implementação manual dos padrões *Singleton*, *Strategy* e *Facade* |
| **Spring Framework** | Inversão de Controle e Padrões de Projeto em uma API REST |
| **Desafio Prático** | Consolidação e estruturação no GitHub para portfólio |

---

## 🚀 Soluções Implementadas

- 🧩 **Padrões em Java Puro:** estruturação manual dos padrões GoF sem frameworks.  
  👉 [Acessar Repositório Java Puro](https://github.com/Rafael-TOZATO/lab-padroes-projeto-java)

- 🍃 **Padrões com Spring:** API REST aplicando abstração e componentes nativos do Spring.  
  👉 [Acessar Repositório Spring Framework](https://github.com/Rafael-TOZATO/lab-padroes-projeto-spring)
