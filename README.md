# Design Patterns com Java: Dos Clássicos (GoF) ao Spring Framework
Projeto prático desenvolvido para o desafio da **DIO (Digital Innovation One)**, com foco no estudo, implementação e aplicação dos principais **Padrões de Projeto (Design Patterns)** clássicos do GoF (*Gang of Four*), demonstrando suas estruturas em **Java Puro** e sua utilidade prática em uma **API REST com Spring Boot**.
---
## 🎯 Objetivo do Projeto
Demostrar a aplicação de padrões arquiteturais em projetos Java para promover código limpo, desacoplado, reutilizável e de fácil manutenção. O repositório centraliza duas implementações complementares:
1. **Java Puro:** Compreensão estrutural e conceitual sem o uso de frameworks.
2. **Spring Framework:** Aplicação real dos padrões integrados a uma API REST com injeção de dependência e facilidades do ecossistema Spring.
---
## 📚 Conteúdo e Módulos

| Módulo | Tema / Foco Principal |
| :--- | :--- |
| **Fundamentos** | Apresentação teórica e introdução aos Padrões de Projeto GoF |
| **Java Puro** | Implementação prática manual dos padrões *Singleton*, *Strategy* e *Facade* |
| **Spring Framework** | Injeção de Dependências e Padrões de Projeto aplicados em uma API REST |
| **Desafio Prático** | Organização, documentação e consolidação no GitHub para portfólio |
